# DORMLY — Dormitory Management App (prototype)

Mobile-first interactive prototype in HTML, CSS and vanilla JavaScript. No build step.

## Run
VS Code Live Server on `index.html`, or open `index.html` in a browser.

## Walkthrough
1. Enter as Resident -> Report issue ("Plumbing leak under the bathroom sink", Room 204, High) -> Submit (DR-2041).
2. Profile -> Switch to Admin view.
3. Requests -> DR-2041 -> Urgent, Marco Santos, In Progress -> Save.
4. Manage -> Switch to Resident view -> Requests -> DR-2041 shows the updates and timeline.

Reset: Profile (Resident) or Manage (Admin) -> Reset data.

## Not included
Rooms/inventory, check-in/out, Lost & Found, search boxes. Data is stored in the browser only (no real backend or login).
